# DS-helper

[English](../README.md) · **Русский**

Бот, который следит за дизайн-системой в Figma и сверяет её с тем, что
реально делает ваша вёрстка. Источник истины — Figma; проверяется код в вашем
репозитории. Системный Python 3, ноль зависимостей, CI из коробки.

**→ [Быстрая интеграция](QUICKSTART.ru.md)** — скопировать, настроить, принять
базовую линию, получить проверку на каждый PR.

**→ [examples/config-r4s.json](../examples/config-r4s.json)** — живая
настройка реального проекта: componentMap, переопределения состояний по
компонентам, чужой хром, выведенный из-под аудита.

Сделан по мотивам Night Watch Figma Librarian от Меты, развёрнутого наизнанку:
там истиной был код, и бот правил Figma; здесь истина — дизайн-система, и бот
проверяет код. Что сохранилось — дисциплина: чекпоинт перед любой правкой,
библиотека никогда не публикуется, человеческие исключения сохраняются,
а не затираются.

## Что умеет

- снимает слепок ДС из Figma: переменные со всеми режимами, компоненты
  с полными матрицами вариантов
- сканирует вёрстку и показывает расхождения с точностью до `файл:строка`
- отличает дрейф значения от «взято из другого режима или акцента»
- находит дефекты самой ДС: дыры в матрицах, дубли имён, опечатки,
  осиротевшие коллекции
- ревьюит изменения ДС между прогонами и собирает карточку для change-log
- роняет CI только на **новых** находках — накопленный долг живёт
  в принятой базовой линии

## Как код сцепляется с Figma

Ничего не угадывается — сцепка живёт в самом коде:

```css
--color-text-primary: #04141f;   /* Color/Text/Default/Primary */

/* ---------- Button ---------- */
.btn { … }
```

Хвостовой комментарий называет Figma Variable; заголовок секции — компонент
ДС. Код без комментариев сцепляется через `componentMap` и сопоставление
значений. Состояния читаются из селекторов (`:hover`,
`[aria-disabled="true"]`, …) — соответствие задаёт `stateMap` в конфиге.

## Запуск

```bash
python3 bin/nw.py            # сканировать, сверить, отчитаться
python3 bin/nw.py --accept   # принять текущие находки за базовую линию
python3 bin/nw.py --fix      # механические правки, сначала чекпоинт
python3 bin/nw.py --promote  # текущий слепок ДС становится базой ревью
```

Отчёты по умолчанию английские; `"lang": "ru"` в config.json переключает
всё — отчёты и CLI — на русский.

## Категории находок

| Код | Значение |
|---|---|
| `TOKEN_VALUE_DRIFT` | значение токена разошлось с Figma Variable |
| `ACCENT_MISMATCH` | значение верное, но из другого акцента ДС |
| `FOREIGN_VARIABLE` | токен назван по переменной чужого кита |
| `TOKEN_UNKNOWN` | токен ссылается на имя, которого в ДС нет |
| `ORPHAN_TOKEN` | объявлен и нигде не используется |
| `RAW_VALUE` | сырое значение там, где есть токен |
| `DEPRECATED_USE` | используется DEPRECATED-компонент |
| `STATE_GAP` | в ДС состояние нарисовано, в CSS не покрыто |
| `MISSING_COMPONENT` | компонент ДС из watchlist отсутствует в коде |
| `DS_DEFECT` | дефект в самой дизайн-системе |
| `NOT_CHECKED` | сверить не с чем — в слепке нет данных |

## Правила честности

Слепок обязан помечать, чего он не знает (`variablesComplete`,
`missingKnown`) — формулировки понижаются до «проверить вручную» вместо
ложных тревог. Авария не путается с находками: находки выходят с кодом 1,
авария — с кодом 4 и видимым stderr. Ложная находка дороже пропущенной —
`nw:ignore`, `outOfScope`, `tier: legacy` и переопределения состояний
существуют, чтобы отчёт оставался читаемым.

## Границы

Никогда не публикует библиотеку Figma, не правит файлы макетов, не судит
о визуале. Правки CSS — только по явному `--fix`, только после записанного
чекпоинта и никогда в `sources`, помеченных как продакшн, — тем достаются
пул-реквесты.

# prototypes/

Сюда переезжают HTML-макеты. Каждый прототип — папка, имя папки = `dir`
в `config.json → prototypes`, а `prototypesRoot` ставится в `"prototypes"`.

Пока папка пуста: макеты — рабочие материалы заказчика, и класть их можно
только в приватный репозиторий. Ветка несёт механику, данные добавляются
после того, как решён вопрос приватности.

Что коммитится вместе с макетами в приватном режиме:
- `config.json` — ключи Figma в приватном репо допустимы
- `snapshots/ds-latest.json` — слепок ДС, его обновляет агент и коммитит
- `snapshots/baseline.json` — принятые расхождения

Чего в репо не должно быть и в приватном режиме: токены (Figma, Telegram) —
только секреты Actions.
